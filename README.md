# EssayAI ML

EssayAI ML is a local machine learning course project for essay score prediction. It provides a Flask web app and a DeBERTa-v3 regression training pipeline. The project includes template-generated sample data so the pipeline can be explored; those samples are not real student essays and do not demonstrate real-world scoring quality.

## Current status

- The local `data/train.csv` contains 2,100 synthetic essays, balanced across scores 1–6. It is regenerated locally and excluded from Git.
- No trained checkpoint is included. Until one is trained, the web app uses a clearly labeled heuristic demo scorer.
- Feedback is generated with simple text-structure heuristics. It is not generated by the transformer or by an external language model.
- No validated model metrics are included. Do not treat sample UI values or synthetic-data results as evidence of grading accuracy.

See [MODEL_CARD.md](MODEL_CARD.md) for intended use and limitations, and [PROJECT_STATUS.md](PROJECT_STATUS.md) for repository and data notes.

## Run locally

Use Python 3.10 or newer. From this directory:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open <http://127.0.0.1:5000>. Without a trained checkpoint the app reports demo mode and uses a non-ML heuristic score.

## Train a model

After cloning, create the synthetic sample CSV if you want to exercise the pipeline:

```powershell
python data/generate_sample_data.py
```

The generated CSV is ignored by Git so a later replacement with licensed/private data is not accidentally committed. Confirm `data/train.csv` has the required `full_text` and `score` columns, then run:

```powershell
python -m src.train
```

Training loads `microsoft/deberta-v3-base` from Hugging Face on first use. It saves the best checkpoint to `outputs/models/best_model.pt` and epoch metrics to `outputs/results/training_log.json`. GPU memory requirements can be substantial; adjust values in `src/config.py` for your hardware.

To train on the Kaggle AES 2.0 data, obtain the data under the competition's terms and replace `data/train.csv` with a compatible CSV. The project does not include or distribute that dataset. Review its column names and score scale before training.

## Command-line prediction

After training, pass a UTF-8 text file:

```powershell
python -m src.predict path\to\essay.txt
```

Without a path, the command reads an essay from standard input until EOF.

## HTTP API

- `GET /api/health` returns service and checkpoint status.
- `GET /api/demo` returns a sample essay.
- `POST /api/score` accepts JSON: `{"essay":"..."}`.

Successful score responses contain `score` on the 1–6 scale, `confidence` (currently `Uncalibrated`), `feedback`, `demo_mode`, and `time_ms`. When no trained checkpoint is available, `demo_mode` is `true`.

## Model outline

The training model uses `microsoft/deberta-v3-base`, the first-token representation, a shared linear head evaluated with multiple dropout rates during training, and sigmoid-bounded MSE regression. Essay input is truncated to 512 tokens by default, so later text may be omitted. See `src/config.py` for hyperparameters.
